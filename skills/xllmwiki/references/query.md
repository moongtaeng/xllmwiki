# 질의 (Query)

위키로부터 답하는 작업. 가치는 답을 추적할 수 있다는 데 있다 — 인용 없는 위키 답변은
답변이 없는 것보다 못하다. 근거가 있는 것처럼 보이지만 실제로는 없기 때문이다.

## 검색

**`wiki/graph/`가 있으면 먼저 질의한다.** 페이지를 읽으면 본문 전체가 컨텍스트에
들어오지만, 질의는 답만 반환한다 — 250페이지 위키에서 이웃 질의 1건이 전체 본문의
0.55%였다.

```bash
python3 "<skill>/scripts/wiki_query.py" find <용어>        # 어느 페이지인지
python3 "<skill>/scripts/wiki_query.py" neighbors <slug>   # 무엇이 연결됐나
python3 "<skill>/scripts/wiki_query.py" facts <slug>       # 근거 있는 관계
python3 "<skill>/scripts/wiki_query.py" path <a> <b>       # 두 페이지가 어떻게 이어지나
```

그래프가 후보를 좁혀준 다음, **실제로 답에 쓸 페이지만** 전문을 읽는다. 그래프의 요약
한 줄을 근거로 답하지 말 것 — 인용은 페이지 본문에서 나온다.

그래프가 없으면 아래 순서로 한다.

`wiki/index.md`부터 시작한다 — 작고, 라우팅 테이블 역할을 한다. 그다음:

```bash
grep -ri '<용어>' wiki --include='*.md' -r -l          # 어느 페이지인지
grep -ri '<용어>' wiki --include='*.md' -r -n          # 좁힐 때는 줄 번호까지
```

중요한 페이지는 전문을 읽는다.

그다음 **두 방향으로 한 단계 확장한다.**

- **링크** — 읽은 페이지의 `[[링크]]`를 한 단계만 따라간다.
- **소스 겹침** — 읽은 페이지의 `sources[]`를 같이 쓰는 다른 페이지를 찾는다. 링크보다
  강한 신호다. 링크는 누군가 걸어야 생기지만 소스 겹침은 저절로 생긴다.

```bash
# 페이지 파일 목록 — 타입 디렉터리 전체, 빈 디렉터리에도 조용하다
PAGES=$(find wiki -mindepth 2 -maxdepth 2 -name '*.md' -not -path '*/graph/*')
grep -l 'raw/<소스 slug>' $PAGES
```

그래프 전체를 순회하지 않는다. 두 방향 각각 한 단계면 충분하다.

사용자가 쓰지 않은 용어로도 검색한다 — 위키는 그 개념을 질문과 다른 이름으로
분류해 두었을 수 있다.

`type: source` 페이지도 함께 본다. "누가 이렇게 주장했나", "그 논문의 한계가
뭐였나" 같은 질문은 개념 페이지가 아니라 소스 페이지가 답한다.

## 답변

주장 단위로, 페이지 slug와 함께 인용한다: `KV 캐시는 메모리를 지불해 지연을 줄인다
[[kv-cache]]`. 답이 틀렸을 때 어느 페이지를 고쳐야 하는지 사용자가 알아야 한다.

위키가 말하는 것과 당신이 덧붙이는 것을 구분한다.

- **위키에 있고 인용된 것** — 답변의 본체.
- **위키 페이지에서 추론한 것** — "추론"이라고 말하고, 어느 페이지에서 나왔는지
  밝힌다.
- **당신의 배경지식** — 위키가 다루지 않는다고 말한다. 위키를 정직하게 유지하는 것이
  바로 이 구분이다. 흐려지면 나중 세션이 무엇이 실제로 근거가 있었는지 판별할 수
  없게 된다.

## 공백을 보고한다

위키가 답하지 못한 것으로 마무리한다. 그 목록이 곧 흡수 백로그이며, 지식베이스가
자신에게 무엇이 없는지 배우는 주된 경로다. `purpose.md`의 핵심 질문 중 아직 답할 수
없는 것이 있으면 그것을 우선순위에 둔다 — 목적이 명시한 공백이 임의의 공백보다 중요하다. 분명히 관련되지만 내용이 얇거나 오래된
페이지(`updated`가 한참 전, `sources`가 비어 있음)가 있으면 그것도 말한다 — 단순한
공백이 아니라 보수 대상이다.

위키에 해당 주제가 전혀 없으면 그렇다고 분명히 말하고 멈춘다. 위키가 뒷받침하는 것처럼
암시하면서 일반 지식으로 답하지 말 것. 대신 소스를 흡수할지 제안한다.
